## 📌 About The Challenge

Welcome to my **100 Days of Data Structures & Algorithms** repository! This project serves as a structured log and portfolio of algorithmic problems solved consistently over a 100-day journey. The objective is to refine algorithmic intuition, optimize time and space complexity analysis, and build a strong problem-solving toolkit primarily using **Java**.

## 🎯 Goals & Methodology
- ⏳ **Consistency**: Solve, analyze, and document algorithmic challenges daily.
- 💡 **Complexity First**: Ensure rigorous estimation of Time ($O(N)$) and Space ($O(N)$) complexities for every solution.
- 🧠 **Pattern Recognition**: Master overarching themes including Two Pointers, Sliding Window, Monotonic Stack, Dynamic Programming, Graph Traversals, and System Design.
- 🧹 **Clean Code**: Write expressive, self-documenting, and robust solutions following best OOP principles.
